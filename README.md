## Entry

`Senior Giraffe Neck Measurer` (28 characters)

A senior specialist title, so it reads like a real job, aimed at one
absurdly specific task: measuring the neck of an animal famous for
already having a very long one. The joke lands on the first read, the
worker is easy to picture with a tape measure and a ladder, and at
28 characters it is taken in at a glance.

## How it works

Run `main.py`. It writes the title, with no trailing newline, to
`/output/entry.txt`, after checking it against the gate: UTF-8 text,
1 to 60 characters, not only white space.

```sh
python3 main.py
```
